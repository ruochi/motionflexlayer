# 摆位

先在分镜的分区表里写每段的标题区、产品区、标记区、故意留白，再写坐标。分区不重叠。产品走进标题区之前，标题先走。

## 规矩

- 字不被卡片、线、图、标记盖住。线停在字的前面。两样东西必须占同一个位置时，字先让开。
- 标记不压在字上。标记周围留出至少它自己那么高的空。
- 两段字不叠在一起。新的一句等旧的离开再进来。交叉淡化最容易在这里出错：透明度还没到 0，`place` 仍会把字留在文档里。
- 标记只在落幅出现。角落里一块一直在的牌子，排版上会和每一段抢位置。它不算「跨段留着的那个元素」。
- 字离画布边缘至少 96 像素。flexlayer 的安全区大约是短边的 4%（1080p 大约 43 像素），比这个更靠里，镜头一推也不容易报 `outside-safe`。
- 东西可以进画出画。停下来的时候，要么整个在画面里，要么明确是大幅出画的出血。卡在边缘外一点点，看起来像没摆好。
- 镜头会改屏幕上的位置。算的是落地之后的位置，不是元素在代码里的名义坐标。
- 1080p 上屏幕字号不要小于 24。`shot()` 的 zoom 和 `place` 的 scale 会把它变小。缩着入场的那几帧，字号要按最小的那一下算。

## 成组

同一组的东西靠得近，组与组之间空得开。所有间距都一样，看起来像列表。

标签贴着它自己的对象，不要贴着旁边那一个。

卡片可以叠，但要叠得明白：被盖住的那张，字不能在上面那张底下。一条细缝的重叠像是排版错了。

## 落幅

落幅是会被截图的那一帧。

- 标记、名字、句子、产品在同一条轴上。字在角落、产品在中间，是两张版式。
- 产品不压字。
- 官方画面里如果已经有大标题，就不要再叠一行自己的标题。参考片没有官方画面，落幅是自己排的一组。
- 单独看最后一帧：眼睛先落到的地方，是不是这支片子要留下的那一个东西。

## 和 check 的关系

`npm run mfl -- check` 会报重叠、出画、字太小、出安全区。品牌片以 error 为零为准。warn 一条条看。画面闸门不看这些，它只看像素满不满、动不动。两道都要过。摆得合法但不好看的，联系表上仍然能看出来。
