# 配乐

画面两道闸门都打印 `0 failed` 之后再写。音乐救不了一支空片子。

节拍从画面里来。找到重复的那一下，量它的间隔，那就是一拍。段界改到这张网上。校线的五项核对每 0.5 秒一项，所以是 120 BPM，最后的红线放在 14.0。

先写每一段有什么、什么停了，再写音符。下面是校线的答案，不是配乐的提纲。

| 段 | 校线 |
| --- | --- |
| 1 | 只有铺底和打字的嘀嗒，发送时一声 |
| 2 | 鼓进来，一项一下，拨弦往上走 |
| 3 | 鼓拿掉，红线是一声扫，卡上的时候才有冲击 |
| 4 | 鼓回来，和弦亮一档 |
| 5 | 先空，14.0 的正拍上冲击、和弦和铃 |

校线在转折拿掉鼓，是为了让那条红线单独被听见。这支片子的空拍放在它自己需要被单独听见的那一下。鼓可以一直在，也可以整段只有一下。

重复的画面用重复的乐句，乐句的形状从那个重复的动作来。校线的五项核对是五声往上的拨弦。另一支片子的重复可以是同一个音、一次比一次短、或者一个一直在的声音被一下一下切断。

## 写在哪

音源可以是文件，也可以是函数。参考片用 `examples/synth` 的合成器，每个音的时间都从时间轴的 cue 来。下面的音高是校线的五项核对，下一部换成自己的重复：

```ts
tl.times('row').forEach((t, i) => {
  syn.kick(t, 0.7)
  syn.pluck(t + 0.04, [67, 69, 72, 74, 79][i]!, 0.11, 0)
})
syn.impact(tl.at('rule'), 1, 1.1)
```

注释写这个音对着画面的哪一下。半年之后，注释是唯一还能解释「为什么 8 秒有一下」的东西。

母线按 MOTION.md 来。品牌片的目标响度用 -14 LUFS，限幅天花板 -1 dBFS。框架里旁白片常用 -16，那是给有人声的片子留的；一支没有旁白的广告，-14 更接近成片。

```ts
master: { lufs: -14, ceiling: -1, fadeOut: 0.4 }
```

## 听不见时怎么核

跑 `npm run mfl -- audio <入口>`，看报告，不要写「好听」。

- 积分响度靠近 -14，限幅不要超过几分贝。
- 各段电平有起伏。高潮比开头响一截，转折比前后轻。
- 每个重要 cue 在波形上能找到一下。
- 波形不是一堵墙，也没有削平的平台。

合成感通常来自这几处：每个音都死在格子上，没有几毫秒的偏差；没有低频；所有声音的混响一样大；一个和弦铺满 15 秒；结尾什么都没有。最后两秒要有一下明确的落地。

交付时说明这些是报告里看到的，声音好不好听要别人用耳朵确认。
