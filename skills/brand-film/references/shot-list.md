# 分镜表

写在合成入口旁边的 `shot-list.md`。格子空着，画面上那一段也会空。下面是一种能填的样子。段数和标题跟着片子走，闸门不认这些标题。

## 隐喻

一个带动作的句子，以及这个动作是从卖点的哪个词、或标记的哪个形态来的。

## 色板

底、字、强调色。强调色为什么只做高光。

## 节拍

一拍多少秒，由画面里的哪一下决定。段界和最后一下落在这张网上。

## 段 1 （名字）

0.0–3.0。产品行为写什么；没有就写「起幅，无」。

镜头：怎么动。

转场：进下一段的方式。最后一段不写转场，写落幅。

| 时刻 | 元素 | 手法 | 缓动 |
| --- | --- | --- | --- |
| 0.20 |  |  |  |

每一段都写镜头，以及它怎么接到下一段。时刻用表，行数跟着这段里真有的事走。

## 段 5 （名字）

镜头：这一段怎么动。校线把拉远放在这里。

落幅：标记和产品在哪一条轴上。

## 自检

勾完再写代码。条数跟着片子增减。

- [ ] 每句画面文字都有出处，编的已经标明
- [ ] 至少两段能看出产品在干什么
- [ ] 至少八种手法
- [ ] 至少两种不是交叉淡化的转场
- [ ] 有一个物件跨过段界，不是角落标记
- [ ] 拉远用在结束的地方
- [ ] 最后一下在正拍上
- [ ] 标记是文件里的那一个，只在落幅出现
- [ ] 落幅是一组，产品不压字

`copy.md` 用表格，列里要有「出处」。`assets.md` 写标记文件和来源。两份都不要留「待填」。
