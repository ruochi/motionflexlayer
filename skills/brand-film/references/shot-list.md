# 分镜表

写在合成入口旁边的 `shot-list.md`。格子空着，画面上那一段也会空。段数、段名、每段多长跟着这支片子走。闸门不认标题，也不认段数。

填好的校线在 `examples/brand/shot-list.md`。那是一份例子，按它的五段和时刻填，拍出来就是校线。

## 隐喻

一个带动作的句子，以及这个动作是从卖点的哪个词、或标记的哪个形态来的。

## 这支片子

四句，各写为什么套不到校线上：

- 材料
- 动词怎么动（手感：短促的一下、不停、硬切，或别的）
- 时间形状（几段，哪一段最长，哪里突然空）
- 镜头

## 色板

底、字、强调色。强调色为什么只做高光。底和强调色从材料来，不从校线的冷纸和红来。

## 节拍

一拍多少秒，由画面里的哪一下决定。段界和最后一下落在这张网上。

## 段 （名字）

起止。产品行为写什么。起幅或落幅没有产品行为，就写明。

镜头：怎么动。

接到下一段：上一段的什么留下，或者怎么切走。最后一段写落幅，不写转场。

| 时刻 | 元素 | 手法 | 缓动 |
| --- | --- | --- | --- |
|  |  |  |  |

一段一节。时刻表的行数跟着这段里真有的事走。手法写这个动词需要的动作。这一页没有的动作，用自己的名字写上。

## 分区

行数和段数一样。

| 段 | 标题区 | 产品区 | 标记区 | 故意留白 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

## 自检

勾完再写代码。条数跟着片子增减。

- [ ] 每句画面文字都有出处，编的已经标明
- [ ] 至少两段能看出产品在干什么
- [ ] 材料、动法、时间形状、镜头，至少三样套不到校线上
- [ ] 相邻的同类元素不用同一种手法
- [ ] 至少两种不是交叉淡化的转场，名字从这支片子的动词来
- [ ] 有一个物件跨过段界，不是角落标记
- [ ] 最后一下在正拍上
- [ ] 标记是文件里的那一个，只在落幅出现
- [ ] 落幅单独能截图，产品不压字

`copy.md` 用表格，列里要有「出处」。`assets.md` 写标记文件和来源。两份都不要留「待填」。
